Sitio web

Taller Testing HITS.

Plataforma web para organización de material de testing.

Sitio web responsive diseñado para organizar materiales, videos y recursos de un taller de testing de software.

El problema

Material didáctico más fácil de recorrer.

El sitio organiza recursos de un taller dentro de una navegación clara y una estructura por módulos, disponible desde escritorio o celular sin infraestructura de servidor.

Módulos destacados

  • Navegación responsive
  • Organización de material didáctico
  • Recursos multimedia
  • Estructura por módulos
  • Publicación web estática

Tecnologías

Una publicación web directa y ligera.

  • HTML
  • CSS
  • JavaScript
  • GitHub Pages
