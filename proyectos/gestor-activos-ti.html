Aplicación de escritorio

Gestor de Activos TI.

Sistema de inventario y control de equipos de cómputo.

Aplicación de escritorio creada para consultar inventario tecnológico, importar datos desde Excel, aplicar filtros y generar reportes en PDF y Excel.

Ver código en GitHub

El problema

Consultar y preparar inventarios con menos fricción.

El proyecto reúne consulta, importación, búsqueda y generación de documentos dentro de una aplicación de escritorio pensada para trabajar con inventarios tecnológicos.

Las capturas usan datos sintéticos para proteger información operativa.

Módulos destacados

  • Inicio de sesión demo
  • Inventario principal
  • Filtros y búsquedas
  • Selección de preguntas
  • Reportes PDF y Excel
  • Importación desde Excel

Tecnologías

Escritorio, datos y documentos.

  • Python
  • PyQt5
  • SQLite
  • Pandas
  • Excel
  • PDF

Galería

Flujos principales de la aplicación.
